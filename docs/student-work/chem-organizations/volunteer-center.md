# 化学学院社会实践与志愿服务督导中心

化学学院社会实践与志愿服务督导中心（简称：社志督）是隶属于化学学院团委的院级学生组织，统管学院志愿服务和社会实践工作。社志督自创建以来一直是一个年轻、团结、充满活力和爱心的集体，下设实践部、办公部、宣传部三个部门。

实践部长期工作： 社会实践审核与考评；负责寒暑假、日常团队及个人社会实践审核；组织“师生同行”暑期社会实践评优答辩；采访优秀实践队。

办公部长期工作：志愿活动申报、志愿时长录入、志愿活动审核、志愿活动保障。

宣传部长期工作：做推送。

另外每个部门下面都可能有一些志愿活动，但这个会有变化，建议参加前先问好活动内容和报酬（有些活动可能需要非常多的“奉献精神”，言尽于此）
