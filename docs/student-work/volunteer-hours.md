# 志愿时长去哪里“水”

（豌豆荚助手）每年 9 月末学校会有运动会，可以报名志愿者，代表学校走个入场式就能拿点时长。

非常建议加入星光科普团，此后每周都有去给小学生讲课、获得志愿时长的机会。就算不想讲课，当个助教给人拍照也能混很多时长。甚至可能都不用外出，综合实验楼就有科普基地，在校内就能刷志愿时长。

科普团里没招满人的活动，一般会发到这个群里，可以蹲一下。

![](images/volunteer-group.jpg)

南开的志愿服务官网是 <https://zyfw.nankai.edu.cn>，上面也会发布一些志愿活动，也可以在这里查看自己参加过的活动及时长。

社会上可能也有一些机会。如果有亲属在一些涉及志愿服务的单位工作，也可以过去参与一下，拿到证明后申请校外活动认证。
