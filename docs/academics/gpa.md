# 平均学分绩点（GPA）

1. 课程学分绩点=课程成绩等级对应绩点×课程学分；平均学分绩点（GPA）=\(\displaystyle \frac{\sum \text{已修课程学分绩点}}{\sum \text{已修课程学分}}\)

2. 主修、辅修的课程分别计算平均学分绩点（GPA）,并将平均学分绩点（GPA）记载于成绩单。

3. 平均学分绩点（GPA）设必修课、必修专选、专业课、全部课程、通识必修课五种测算方式。

> 注解：
>
> 总评指的是平时成绩和考试成绩的加权平均，比如大家常常说的四六开，七三开。
>
> 以四六开为例，四指的是平时分占40%，考试占60%，例如某人有机2-2平时分92分，考试83分，那他的总评就是92*0.4+83*0.6=86.6，在绩点制下即3.7（悲报：有机2-2和2-1均已改为三七开）。注意，化院的考试多少开不会变化，捞只能在这个范围捞：比如给考试分开根号×10，但是最好不要把希望寄托在那上面。另外，24级伯苓平时分严格正态分布于{95,92……80}or{98,95……80},大类只有少数课设强制正态分布，但是没做作业下不封底。
>
> ABCDE课的区别：A课是通识必修课，包括高数、大物、思政、体育、英语等；B，C课都是专业必修课，不必区分，例如四大化学和其各自的实验；D课是专业选修课，比如有机波谱解析，化学专业英语（这两个要闭卷考试要学了才能得4），或者说功能配合物，质谱（比较好得4，论文结课）。E课则是通识选修课，这里不做课程推荐，保证绩点高，事情少即可。
>
> 部分D课为指定D课，即保研必须要修的D课，这些课需要在大三下之前修完。
