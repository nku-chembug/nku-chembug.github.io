# 关于 D 课

## 化学专业英语

首先我要声明，这门课讲授的内容对于化学科研是很重要的，因为掌握基本的化学物质英文名称和英文命名规则，对于做科研，特别是读文献和写论文，是必不可少的。

当然，作为一门语言类课程，这门课程的内容非常多。如果你在大学之前对化学很感兴趣，已经对有关英文词汇有了系统性的了解（比如我有一位同学，每个元素的英文名称都会拼写，无机物、有机物、配合物的命名规则也都掌握了），那可能会比较轻松。但是，如果你在此前的化学学习中没有着重关注过化学中的英文用语，那这门课有可能很有挑战性。你不能指望仅靠上课时间来获得一个好成绩，课下至少要投入与课堂等量的时间（参考了另一位获得了好成绩的同学的经历），不能像我一样仅靠上课和考前复习。

据我所知，23 和 24 级这门课程的期末考试都是安排在高数下考试那一天的早上八点。也就是说，如果平时的学习不够充分，就势必要拿出很大一部分宝贵的高数复习时间来背记化学专业词汇，这样不仅很消耗时间，更消耗脑力。而高数是很需要考前充分复习和做往年题提升手感的。

当然，我说这么多，没有任何劝进或者劝退的意思。我只是想说，不要抱着花费较少精力来获得不错成绩的心态学习这门课程；这门课程是需要一定投入的。

## 应用化学分析

应化的仪器分析，背诵为主，重点在各类仪器的原理、构造等，计算内容较少，内容可多方参考作业题和知识点总结。值得注意的是有两个解谱题：其一是核磁、红外、紫外的综合分析，另一是单纯核磁。难度中等，建议认真备考，仍然以背诵为主。

## （全英）有机化合物结构鉴定

（豌豆荚助手）这门课讲质谱和核磁，质谱主要是关于原理，核磁更侧重于解谱，具体包括氢谱、碳谱、DEPT，二维谱中的 COSY、NOESY 和 NOE。除了全英算个小门槛之外，课程难度并不算高，认真学一学期，基本能解复杂化合物的核磁谱图了。考试开卷，kxl 和 wzh 都是非常好的老师，喜欢有机的同学可以闭眼冲。

## 有机结构分析（cl）

这门课纯教解谱，主要有质谱、红外、核磁（氢谱、碳谱、杂原子谱、DEPT、COSY、NOESY 等），实用价值很高，单就这一点很推荐选。课程每节课都有作业，主要是解谱，但是还要求你归纳笔记。最后考试是随堂、闭卷，概念题占比较大，最后有一道很综合的解谱题，这玩意能做出来的话，那这门课是真学会了。
