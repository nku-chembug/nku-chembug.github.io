# 关于选课

选课网站：https://eamis.nankai.edu.cn ；这个网站非常实用，上面可以查看你的绩点、排名，同时选课也需要在这上面操作。建议使用电脑，在链接学校VPN且网络通顺的情况下进行选课，一般的选课顺序为：优先抢体育课，其次是不太好抢的E课或者D课，最后抢专业课。（注意E课对于不同模块的学分有要求，注意关注每年的选课手册和你自己的选课情况，另外有些课程在选课手册上是D课，但是在eamis上显示为E课，注意这时候以eamis显示为准，例如应用电化学，该退课就果断退课）。另外如果选不到理想的体育课可以等到大三上半学期再补，这个不着急。曾经伯苓硬性要求大二下修完体育，现在也放宽了，没必要为了赶进度而选一个自己不擅长的运动折磨自己。

关于掉课：A课可以超选10%，之后随机掉课；其余课程均可无上限选择，最后随机掉课。
